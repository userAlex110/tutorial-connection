## 这是什么？

一个开源的知识分享网站，专注于帮助理工科背景的朋友们建立真诚的人际关系。

作为理工科背景的人，我们在技术领域可能很擅长，但在人际关系方面可能会感到困惑——因为这里没有明确的文档、没有标准的 API、也没有可以 debug 的错误日志。

这个网站的目标是提供实用的见解和经验分享，帮助大家在保持真实自我的同时改善人际关系。
