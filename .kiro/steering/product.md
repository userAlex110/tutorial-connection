# Product Overview

## Authentic Connections (真诚连接)

一个开源的知识分享网站，专注于帮助理工科背景的男性建立真诚的人际关系。以文档为核心，分享实用的见解和经验。

## Core Philosophy

- **真诚第一**: 帮助用户在保持真实自我的基础上成长
- **内容为王**: 专注于有价值的知识和经验分享
- **简洁实用**: 避免复杂功能，专注于内容的呈现和阅读体验
- **开源协作**: 欢迎社区贡献内容和改进

## Target Audience

- 理工科背景的男性
- 希望改善人际关系的个人
- 重视真诚而非表面社交技巧的用户
- 喜欢结构化知识分享的人群

## Key Features

- **文档优先**: 以Markdown文档为核心的知识分享
- **简洁导航**: 清晰的内容组织和导航结构
- **响应式设计**: 在各种设备上都有良好的阅读体验
- **静态部署**: 可部署到任何静态托管平台
- **搜索友好**: 易于搜索和浏览的内容结构
