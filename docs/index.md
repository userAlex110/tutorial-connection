## 这是什么？

一个开源的知识库，专注于帮助理工科背景的朋友们建立真诚的人际关系。

作为理工科背景的人，我们在技术领域可能很擅长，但在人际关系方面可能会感到困惑——因为这里没有明确的文档、没有标准的 API、也没有可以 debug 的错误日志。

这个网站的目标是提供**系统化的知识框架**和**可操作的实践指南**，帮助大家在保持真实自我的同时改善人际关系。

## 核心理念

<div class="grid cards" markdown>

-   :material-heart:{ .lg .middle } __真诚第一__

    ---

    我们不教"套路"，那些东西就像给代码加混淆——短期可能有效，但长期维护成本极高

-   :material-account-arrow-up:{ .lg .middle } __自我提升优先__

    ---

    恋爱的本质是吸引力，先把自己的 Core 修好

-   :material-brain:{ .lg .middle } __理解而非操控__

    ---

    从心理学角度解释"为什么"，而不是机械地执行"怎么做"
