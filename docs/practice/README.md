# 作者实践记录

> 理论是地图，实践才是旅程。这里记录我（网站作者）在真实场景中的应用、踩坑和反思。

---

## 为什么写这个？

这个网站提供了系统化的方法论，但**知道和做到之间隔着太平洋**。

我在这里记录：
- ✅ 哪些技巧真的有效
- ❌ 哪些理论在现实中翻车
- 🤔 实际执行时的微妙感受
- 📈 从新手到熟练的进化轨迹

这不是「成功案例展示」，而是**真实的实验记录**——包括失败和尴尬。

---

## 阅读指南

每篇记录包含以下结构：

| 模块 | 说明 |
|------|------|
| **背景** | 什么阶段、什么场景、目标是什么 |
| **执行** | 用了哪些技巧，具体怎么操作的 |
| **结果** | 对方反应、氛围如何、是否达成目标 |
| **反思** | 哪里做得好，哪里可以改进 |
| **迭代** | 下次要调整什么 |
