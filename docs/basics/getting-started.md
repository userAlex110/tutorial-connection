# 开始指南

欢迎来到真诚连接！这是一个专为理工科背景朋友设计的人际关系知识库。

## 为什么需要这个网站？

作为理工科背景的人，我们习惯用逻辑和系统思维解决问题。但在人际关系领域，很多人会感到困惑——因为这里没有明确的文档、没有标准的 API、也没有可以 debug 的错误日志。

这个网站的目标是：**用理工男能理解的方式，讲清楚人际关系这件事。**

## 核心理念

### 1. 真诚第一

我们不教"套路"和"话术"。那些东西就像是给代码加混淆——短期可能有效，但长期维护成本极高，而且容易崩溃。

正如王小波在《爱你就像爱生命》中所展示的，开启一段关系最好的敲门砖不是展示你有多少钱或多完美，而是**"毫无保留的赤诚"**。这种坦荡的示弱和天真的热情，是建立信任最快的捷径。

真诚的关系就像开源代码：透明、可维护、经得起 review。

### 2. 自我提升优先

恋爱的本质是吸引力。与其研究怎么"追"，不如先把自己的 Core 修好。

> 你若盛开，蝴蝶自来。

### 3. 理解而非操控

我们从心理学、社会学的角度解释两性差异，帮助你理解"为什么"，而不是机械地执行"怎么做"。

## 内容结构

### 📚 文章

深度内容，分为三个主要模块：

- **自我认知** - 了解自己是一切的基础
- **沟通技巧** - 学会有效的"通信协议"
- **关系建立** - 从认识到深入的完整路径

### 📖 指南

实用的操作手册，包括：

- 形象管理入门
- 社交场景指南
- 常见问题排查

### 🔗 资源

推荐的书籍、课程和工具。

## 一个重要提醒

这个网站的内容都是建议和参考，不是"标准答案"。每个人的情况不同，每段关系也不同。

最重要的是：**保持真诚，尊重他人，也尊重自己。**
